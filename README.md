# Chatbot

This repository will contain a chatbot application.

## Planned Architecture

- **Frontend:** Next.js, React, and TypeScript
- **Backend:** FastAPI, Python, and SQLAlchemy
- **Database:** SQLite
- **AI:** OpenAI API

The application itself has not been implemented yet. Project documentation will be added under `docs/`, and the frontend and backend will be introduced when their implementation begins.

## Development Notes

Keep secrets in a local `.env` file and never commit it. When environment variables are introduced, document required names in `.env.example`.
